# Lesson 10: Writing it up as a short paper

⏱ **90 minutes** · Open `lesson.ipynb`, run top to bottom, answer each 🤔 first. Then start
your draft from `paper_template.md`.

**You'll be able to:** structure a short empirical paper, write evidence-matched result
sentences generated from stored tables, and report absent results honestly.

**You need:** Lesson 09.

**Stuck on the checkpoint?** `solution.py`, but try for 10 minutes first.

## Common errors

| You see | Why | Fix |
|---|---|---|
| Checker shows a one-character difference | Spacing or punctuation | Copy the f-string pattern exactly, including the final full stop |
| `NameError: ci` | Helper not imported | It is imported in the first cell; run cells in order |
| Your claim is "UNSUPPORTED" | The evidence is not there | Delete or weaken the claim, don't hunt for another test |

**Next:** run the real study (`make reproduce`) and draft your paper.
